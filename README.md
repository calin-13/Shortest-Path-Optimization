# Shortest Path Optimization – Luxembourg Road Network

A Java-based application that computes shortest paths on a real-world road network using Dijkstra and Bellman-Ford algorithms.

## Features

- Shortest path computation between locations
- Support for weighted graphs, including negative edges
- Comparison between Dijkstra and Bellman-Ford algorithms

## Tech Stack

- Java
- Graph algorithms

## Description

The application processes a graph representation of Luxembourg’s road network and calculates optimal routes between nodes. It focuses on algorithmic efficiency, correctness, and real-world applicability of graph theory.
